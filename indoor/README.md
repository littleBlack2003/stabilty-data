| 项目 | 参数 |
|---|---|
| 数据采集 | 2026-11-04 16:37 起连续运行（本快照截止 2026-11-05 18:11，约 25.6 h / 304 轮） |
| 通道 | 16 通道顺序扫描，每片约 8 s，一轮约 5 min |

## 有效通道

固定剔除 **C003 / C007 / C009**（全程 Voc 只有 0.05–0.35 V、FF 25–37%，接触不良/短路），
剩 13 片参与统计：MoOx/Ag 6 片、PEDOT-F/Ag 7 片。

另：**第 0 轮**（2026-11-04 16:37–16:39）整体 Isc 只有后续的一半，判定为光源未稳定，
标记 `LOW_LIGHT`，不参与统计与归一化基准。

## 当前结果（本快照）

```
组别          片数  PCE0中位  末点归一化中位   范围              全程衰减率中位
MoOx/Ag        6    14.90%    91.14%      89.81~93.17%      -0.44 %/h
PEDOT-F/Ag     7    15.70%    97.16%      96.14~110.12%     -0.19 %/h
```

- 初始效率差：MoOx/Ag 比 PEDOT-F/Ag 低 **0.80 个百分点（绝对值）**
- 末点归一化差：MoOx/Ag 比 PEDOT-F/Ag 低 **6.02 个百分点**，差距仍在扩大
- T80：两组均未达到

## 结论要点

1. **PEDOT-F/Ag 明显更稳**：末点归一化中位 97.16% vs 91.14%
2. **损失机制**：Voc 几乎不变（98.3~100.1%），FF 掉 3~7 个百分点，Isc 掉 0~4 个百分点
   → 主因是串联电阻/界面退化与光电流收集体变差，而非活性层吸收退化
3. **两体系的实质差异在 Isc**：MoOx/Ag 归一化 Isc 96.0~97.8%、PEDOT-F/Ag 99.0~102.0%
   → MoOx 侧额外损失约 2~3% 的光电流
4. **C013 是异常个例**：归一化 PCE 110.12%（FF 从 64.9% 爬到 70%+，光浸泡未收敛），
   看体系均值时建议单独对待
5. **MoOx/Ag 组内一致性高**（89.81~93.17%），说明差异是体系性的，不是个别片偶然

## 关于 1 h 窗口（重要）

1 h 窗口只有约 12 个点，**对光源变化极其敏感**。本快照就遇到了：

```
2026-11-05 18:05 第 302 轮：13 片 Isc 同时 +2.2%（Voc 不变）→ 光源变亮的阶跃
```

结果这一轮的上升把 1 h 斜率整体拉成正的（MoOx/Ag 中位 **+0.99 %/h**、
PEDOT-F/Ag 中位 **+1.45 %/h**），报告里因此出现「在回升」的判定——这是**光源伪迹，不是器件真的变好**。

脚本现在会在报告里自动告警（尾窗内相邻轮中位 Isc 变化 ≥ 1.5% 即提示）：

```
注意：尾窗（1 h，12 轮）内检测到 1 次光强跳变（|Δ中位 Isc| ≥ 1.5%），末端斜率可能被光源变化主导：
  第 302 轮 18:05  中位 Isc +2.2%
  → 建议延长窗口（--tail-hours 2）或先做光强校正再判稳定
```

**建议**：判断是否稳定时不要只看 1 h，至少同时看 2 h / 4 h 窗口，或等光源跳变过去后再复核。
若确认要长期用 1 h 窗口，应先把光强校正（`--light-correct`，用每轮中位 Isc 作内部光度计）做完。

## 已知问题 / 注意事项

- **光源缓慢衰减 + 偶发跳变**：以每轮中位 Isc 作为内部光度计，25 h 内整体下降约 2%，
  平均速率约 **−0.20 %/h**，并在 18:05 出现一次 +2.2% 的阶跃（可能是灯电源波动或光路动了）。
  这是共模漂移，会直接算进 Isc/PCE 的归一化值；**本快照未做光强校正**。
- 因此「末端斜率」判据（默认 |斜率| ≤ 0.10 %/h）目前偏严，13 片全部未达标；
  若要在此漂移水平下判定稳定，建议改 `--stable-slope 0.25`。
- 表头 `Etac(%)` 无意义（占位值放大 100 倍），一律用 `summary_cells.csv` 的 `PCE0(%)`。
- 测试仍在进行，本目录是**时间点快照**；重新运行 `publish_indoor.bat` 即可刷新全部输出并推送。
