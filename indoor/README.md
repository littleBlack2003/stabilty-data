## 结论要点

1. **PEDOT-F/Ag 明显更稳**：末点归一化中位 96.66% vs 91.14%
2. **PEDOT-F/Ag 已接近平台**：5 h 末端斜率中位 −0.159 %/h，与光源自身漂移速率
   （约 −0.18 %/h）基本相当 → **真实衰减接近 0，剩下的都是光强漂移的共模贡献**
3. **MoOx/Ag 仍在真实衰减**：5 h 斜率 −0.540 %/h，R² 0.75~0.88（线性良好），
   扣除光源漂移后约 **−0.36 %/h**
4. **损失机制**：Voc 几乎不变（98.3~100.1%），FF 掉 3~7 个百分点，Isc 掉 0~4 个百分点
   → 主因是串联电阻/界面退化与光电流收集体变差，而非活性层吸收退化
5. **两体系的实质差异在 Isc**：MoOx/Ag 归一化 Isc 96.0~97.8%、PEDOT-F/Ag 99.0~102.0%
   → MoOx 侧额外损失约 2~3% 的光电流
6. **C013 是异常个例**：归一化 PCE 109.96%（FF 从 64.9% 爬到 70%+，光浸泡未收敛），
   看体系均值时建议单独对待
7. **MoOx/Ag 组内一致性高**（89.81~93.17%），说明差异是体系性的，不是个别片偶然

## 关于 5 h 窗口与线性拟合（重要）

窗口从 1 h 改为 5 h 的直接原因：**1 h 窗口只有约 12 个点，一次光强跳变就能把结论带反**。
本数据集里真实发生过：

```
2026-11-05 18:05  第 302 轮
13 片 Isc 同时 +2.2%，Voc 不变  → 光源变亮的阶跃
```

- 用 **1 h** 窗口时：MoOx/Ag 中位斜率 **+0.99 %/h**、PEDOT-F/Ag **+1.67 %/h** → 被判成「在回升」，纯属伪迹
- 用 **5 h** 窗口时：这 60 轮里同一阶跃的权重被摊薄，得到 −0.540 / −0.159 %/h，与 2 h、4 h 口径一致

为避免"看起来拟合了、其实拟合没意义"，报告里同时给出 **R²**（PCE 归一化值对时间的线性拟合决定系数）：

| 组别 | R² 范围 | 解读 |
|---|---|---|
| MoOx/Ag | 0.75 – 0.88 | 衰减接近线性，斜率可信 |
| PEDOT-F/Ag | 0.10 – 0.50 | **残余变化已是噪声量级**，斜率接近 0，只能当作"无显著衰减"看 |

脚本会自动告警尾窗内的光强跳变（相邻轮中位 Isc 变化 ≥ 1.5%）：

```
注意：尾窗（5 h，60 轮）内检测到 1 次光强跳变（|Δ中位 Isc| ≥ 1.5%），末端斜率可能被光源变化主导：
  第 302 轮 18:05  中位 Isc +2.2%
  → 建议延长窗口（--tail-hours 10）或先做光强校正再判稳定
```

**建议**：判稳定时同时看 1/2/5 h 三个口径 + R²；若确认要长期用短窗口，应先做光强校正
（`--light-correct`，用每轮中位 Isc 当内部光度计，目前未实现）。

## 已知问题 / 注意事项

- **光源缓慢衰减 + 偶发跳变**：以每轮中位 Isc 作为内部光度计，25 h 内整体下降约 2%，
  平均速率约 **−0.18 %/h**，并在 18:05 出现一次 +2.2% 的阶跃（可能灯电源波动或光路被动过）。
  这是共模漂移，会直接算进 Isc/PCE 的归一化值；**本快照未做光强校正**。
- 「末端斜率」判据默认 |斜率| ≤ 0.10 %/h 在此漂移水平下偏严（PEDOT-F/Ag 扣掉漂移后达标，
  但按原始数据算 0/13 达标）；若要直接判稳定，可用 `--stable-slope 0.25`。
- 表头 `Etac(%)` 无意义（占位值放大 100 倍），一律用 `summary_cells.csv` 的 `PCE0(%)`。
- 测试仍在进行，本目录是**时间点快照**；重新运行 `publish_indoor.bat` 即可刷新全部输出并推送。
