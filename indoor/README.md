## 有效通道

固定剔除 **C003 / C007 / C009**（全程 Voc 只有 0.05–0.35 V、FF 25–37%，接触不良/短路），
剩 13 片参与统计：MoOx/Ag 6 片、PEDOT-F/Ag 7 片。

另：**第 0 轮**（2026-11-04 16:37–16:39）整体 Isc 只有后续的一半，判定为光源未稳定，
标记 `LOW_LIGHT`，不参与统计与归一化基准。

- T80：两组均未达到

## 结论要点

1. **PEDOT-F/Ag 明显更稳**：末点归一化中位 95.56% vs 90.84%
2. **损失机制**：Voc 几乎不变（99.2~100.2%），FF 掉 3~6 个百分点，Isc 掉 1~4 个百分点
   → 主因是串联电阻/界面退化与光电流收集体变差，而非活性层吸收退化
3. **两体系的实质差异在 Isc**：MoOx/Ag 归一化 Isc 96.5~97.8%、PEDOT-F/Ag 99.4~100.5%
   → MoOx 侧额外损失约 2~3% 的光电流
4. **C013 是异常个例**：归一化 PCE 107.84%（FF 从 64.9% 爬到 70.1%，光浸泡未收敛），
   看体系均值时建议单独对待
5. **MoOx/Ag 组内一致性高**（89.52~93.17%），说明差异是体系性的，不是个别片偶然

## 已知问题 / 注意事项

- **光源缓慢衰减**：以每轮中位 Isc 作为内部光度计，20 h 内下降约 2%，当前速率约 **−0.20 %/h**。
  该漂移是共模的，会算进 Isc/PCE 的归一化值。扣除后 PEDOT-F/Ag 真实衰减接近 0，
  MoOx/Ag 约 −0.35 %/h。**本快照未做光强校正**（`--light-correct` 尚未加入）。
- 因此「末端斜率」判据（默认 |斜率| ≤ 0.10 %/h）目前偏严，13 片全部未达标；
  若要在此漂移水平下判定稳定，建议改 `--stable-slope 0.25`。
- 表头 `Etac(%)` 无意义（占位值放大 100 倍），一律用 `summary_cells.csv` 的 `PCE0(%)`。
- 测试仍在进行，本目录是**时间点快照**；重新运行脚本即可刷新全部输出。
