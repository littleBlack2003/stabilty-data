# 稳定性数据后处理脚本 `stability_report.py`

只读分析 `MEAS/` + `STAT/` 原始数据，**测试软件运行期间可随时执行**（不写 MEAS/STAT、不加文件锁），
结果统一输出到数据目录下的 `REPORT/` 子目录。

## 常用命令

```powershell
# 单次分析（结果写到 D:\zlc2026年11月4日\REPORT\）
python tools/stability_report.py --data "D:\zlc2026年11月4日"

# 边测边看：每 2 分钟刷新一次，Ctrl+C 退出
python tools/stability_report.py --data "D:\zlc2026年11月4日" --watch 120

# 光强默认按 0.55 sun（= 55 mW/cm²）算效率；改 1 sun 或改面积：
python tools/stability_report.py --data "..." --suns 1.0
python tools/stability_report.py --data "..." --irradiance 55 --area 0.1

# 换分组文件（兼容 StabLabProcessor 分组 CSV）；默认 1-8 / 9-16 两个体系
python tools/stability_report.py --data "..." --groups "StabLab-默认分组.csv"

# 改剔除名单 / 恢复全部通道 / 放宽有效判据
python tools/stability_report.py --data "..." --exclude 3,7,9,13
python tools/stability_report.py --data "..." --exclude none
tools/stability_report.py --data "..." --ff-min 45 --voc-min 0.5
```

## 自动刷新（已配置：每 5 分钟）

当前这台机器上已在后台跑着（只读原始数据，不影响测试软件）：

```powershell
# 查看日志
type "D:\zlc2026年11月4日\REPORT\_refresh.log"

# 确认进程还在
Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
  Where-Object { $_.CommandLine -like '*stability_report*' } |
  Select-Object ProcessId, CommandLine

# 停止
Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
  Where-Object { $_.CommandLine -like '*stability_report*' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```

- 刷新间隔 300 秒（5 min）；一轮实测约 5 min（16 片 × 8 s），够用
- 输出目录里的 `.watch.lock` 记录刷新进程 PID，保证**只跑一个实例**；
  再启动会自动提示「已有自动刷新进程在运行」并退出；进程被强杀后残留的锁会在下次启动时自动接管
- 日志：`REPORT\_refresh.log`（每次刷新追加一条 `完成：...`）
- 重启电脑后后台进程不会自己恢复，需要重新执行一次启动命令（或把
  `tools/stability_report_watch.bat` 放进「启动」文件夹 / 任务计划程序）

手动前台运行（可以直接看到输出，Ctrl+C 停止）：

```powershell
python tools/stability_report.py --data "D:\zlc2026年11月4日" --watch 300
```

## 自动刷新

脚本**默认只跑一次**就退出；要边测边刷新必须加 `--watch N`（N = 秒）：

```powershell
python tools/stability_report.py --data "D:\zlc2026年11月4日" --watch 120
```

- 每 N 秒重新扫一遍 `MEAS/`+`STAT/`，有新数据就重算并覆写 `REPORT/` 下全部文件
- 一轮约 5 min（16 片 × 8 s），所以 120 s 足够，扫一次只需 0.1~1 s
- 终端窗口要一直开着；Ctrl+C 或关窗口即停止，不会留后台进程
- 也可以双击 `tools/stability_report_watch.bat`（顶部可改数据目录和间隔）
- 想彻底无人值守：任务计划程序里跑上面那条命令即可
- CSV/图被 Excel、Origin、看图软件占用时会打印「被占用，本轮未更新」，**不会中断**，关掉文件后下一轮自动补上

## 输出位置

默认写到 **数据目录下的 `REPORT` 子目录**（与软件的 `MEAS`/`STAT` 平级），例如
`D:\zlc2026年11月4日\REPORT\`。测试软件只往 `MEAS`/`STAT` 写文件、且从不扫描其他目录，
所以放同一父目录不影响采集；`--out` 可改位置，但会被禁止写进 `MEAS`/`STAT`。

## 输出文件

| 文件 | 内容 |
|------|------|
| `report.txt` | 总结：参数、轮次表、每片指标、**分组对比**、QC 统计、阶段性结论、注意事项 |
| `summary_cells.csv` | 每片一行：PCE0 / 四个参数的首末值与末点归一化 / 衰减率 / T80 / T90 |
| `summary_groups.csv` | 每组一行（`group` 为全名、`group_short` 为短名）：片数 / PCE0 中位 / 末点归一化中位与范围 / T80 中位 / 最佳最差 |
| `points_all.csv` | 长表，每次测量一行（重算指标 + 有效性 + 标记） |
| `aligned_pce.csv` + `aligned_{pce,isc,voc,ff}_norm.csv` | 宽表，行=时间、列=电池片，可直接进 Origin（四个归一化都用同一基准点） |
| `aligned_group_mean.csv` | 按轮对齐的分组均值（两个体系，含参与片数） |
| `rounds.csv` | 每轮中位 Isc/PCE、有效片数、光强是否偏低（`lamp_ok`）、是否测完（`complete`） |
| `fig_pce.png` | **八联图**：4 行 × 2 列，左列 PCE / Isc / Voc / FF 原始值，右列各自归一化（细线=单片，粗线=分组均值±SD，100% 点线为参考） |
| `fig_group.png` | 分组对比图（两个体系均值 ± SD） |
| `fig_ranking.png` / `fig_iv_last.png` | 末点排名、最近一轮 IV 曲线 |

## 默认分组与固定剔除

| 配置 | 默认值 | 修改方式 |
|------|--------|----------|
| 分组 | `1-8` = ZnO/D18:L8/MoOx/Ag，`9-16` = ZnO/D18:L8/PEDOT-F/Ag | `--groups 分组.csv`（兼容 StabLabProcessor 格式） |
| 剔除 | `C003 / C007 / C009`（Voc/FF 长期不达标、接触不良） | `--exclude 3,7,9,13` 或 `--exclude none` |

分组统计（`summary_groups.csv`、`aligned_group_mean.csv`、`fig_group.png`）**按轮次对齐**而非按精确时间戳：
16 片是顺序扫描的（每片约 8 s），同一时刻只有 1 片有数据，按时间戳聚合会出现锯齿。

另外片数不足正常轮 80% 的轮次（通常是正在测的最后一轮）标 `complete=N`，
**不参与分组均值**——否则 n 从 6 掉到 1 会让均值假跳一下。
该判断是**按组**做的：整轮 13 片里测了 11 片算完整，但若某个组只测到 2 片，该组此轮仍会被剔除。

## 计算口径

原始 TXT 的 `Etac(%)` 用了占位值 `Irradiance=1.000`，所以放大 100 倍（862% 实际是 8.62% @1 sun）。
本次测试名义光强按 **0.55 sun（55 mW/cm²）** 计算（`DEFAULT_SUNS=0.55`），效率约为 1 sun 口径的 1.82 倍。
脚本一律从 IV 曲线重算：

```
Isc  = |I(V=0)|                    Pmax = max(-V·I)
Voc  = V(I=0)                      FF   = Pmax / (Isc·Voc)
Jsc  = Isc / Area                  PCE  = Pmax / (Area · Irr) × 100 %
```

## 有效性 / 标记

| 标记 | 判据（默认，可用 CLI 改） | 含义 |
|------|--------------------------|------|
| `VOC_LOW` | Voc < 0.40 V | 接触不良 / 短路片 |
| `FF_LOW` | FF < 40 % | S 形曲线 / 串联电阻过大 |
| `ISC_LOW` / `PMAX_LOW` | Isc < 0.05 mA / Pmax < 0.01 mW | 几乎无输出 |
| `LOW_LIGHT` | 该轮中位 Isc < 全局中位 × 0.85 | 光源异常/预热，整轮不参与统计与归一化 |
| `HDR_MISMATCH` | 表头与曲线重算偏差 > 5 % | 记录与扫描不同步，需核对 |
| `CURVE_BAD` / `NAN` | 曲线不完整或参数无法求出 | 丢弃 |

带上述标记的点仍保留在 `points_all.csv` 里，只是不进统计、不画曲线。

## 归一化基准 `--baseline`

- `first-round`（默认）：第一轮**光强正常**且该片有效的点
- `firstN:3`：前 3 个有效点中位数
- `best`：全程最高 PCE

T80/T90 只做线性插值，点数不足时报告里显示「未达 / —」，不会硬拟合。

## 安全设计（为什么不影响正在运行的软件）

- 只以 `rb` 只读打开，读完立即关闭，不加排他锁；
- 修改时间 < 2 s 的文件跳过（可能正在写），`--min-age` 可调；
- 半截文件只取完整行，点数不足自动跳过，不抛异常；
- 输出写到 `<数据目录>/REPORT`（与 MEAS/STAT 平级），不允许写进 MEAS/、STAT/；
- 写 CSV/PNG 用 `.tmp` + 原子替换，不会出现半个文件。
